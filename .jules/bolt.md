## 2024-11-20 - [Optimizing Graph Node Updates and Rendering with Map-based Lookups]
**Learning:** In applications with complex graph structures (like scenes and quests), bulk updates to node positions can become a performance bottleneck when using $O(N \times U)$ search patterns. Switching to a $O(N + U)$ pattern using a pre-constructed `Map` for lookups significantly improves responsiveness, especially during dragging operations. Similarly, memoizing lookup maps within React components (using `useMemo`) eliminates repeated array searches during the render loop of complex SVGs and connection paths.
**Action:** When performing bulk updates on collections or rendering connections between items in a list, always consider pre-constructing a `Map` if the lookup key is known. In React components, memoize these maps to ensure stable and fast lookups across re-renders.
