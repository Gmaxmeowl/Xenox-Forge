## 2025-02-15 - [Map-based lookup for bulk store updates]
**Learning:** Bulk updates of positions inside a list-based store (such as `scenes` and `questStages`) using `Array.prototype.find` has $O(N \times U)$ complexity. This slows down dragging operations in large lists (e.g., 10,000 items). By converting the updates array to a `Map` first, we can optimize the complexity to $O(N + U)$, reducing the update time by ~11x. To maintain exact semantic equivalence, if there are duplicate IDs in the updates array, we must only record the first occurrence in the Map (using `if (!map.has(id)) map.set(...)`).
**Action:** When performing bulk updates on lists based on another list/array, always build a lookup `Map` first, and ensure semantic equivalence with `.find()` if duplicate keys can exist.
