## 2024-11-20 - [Zustand Bulk Update Map Optimization]
**Learning:** In interactive, node-based flowchart tools (like graph editors), batch coordinate updates (such as dragging selected items or quest stages) trigger high-frequency state updates. Mapping over thousands of scenes and performing nested `.find()` operations to find matching coordinate updates can result in an quadratic $O(N \times U)$ complexity. Refactoring this to prepare a single lookup `Map` ahead of time reduces the time complexity to $O(N + U)$, which yielded an incredible ~27x speedup (~12000 ms down to ~440 ms for 10,000 items under 1000 iterations).
**Action:** Always optimize batch state updates over array-based data structures in Zustand by hashing/mapping lookups rather than executing nested linear lookups inside mapping operations.
