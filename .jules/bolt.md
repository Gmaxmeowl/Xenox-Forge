## 2025-05-15 - GraphView Rendering Optimization
**Learning:** Rendering complex graph visualizations in React can lead to quadratic scaling issues (O(N^2) or O(E*N)) if lookups (like finding target scenes for edges) are performed using `array.find` inside the render loop. Additionally, subscribing to a large monolithic state object in the main view causes unnecessary re-renders for every change in the project. Even with `React.memo`, re-renders can still occur if callback props are unstable (e.g. anonymous functions created in the parent).
**Action:** Use `useMemo` to create a `Map` for constant-time lookups (O(1)) of related data during complex rendering. Extract items into separate components wrapped in `React.memo` and use stable callbacks (via `useCallback` and `useRef` for values like `scenesMap`) to ensure that `React.memo` actually prevents unnecessary re-renders of static nodes during high-frequency updates like dragging.
