## 2025-05-20 - Map-based lookup for bulk position updates in Zustand store
**Learning:** During drag operations in GraphView and QuestEditor, `updateScenesPositions` and `updateQuestStagesPositions` in `useStore.ts` are called on every `mousemove` frame with an array of updated node positions. Performing a nested `updates.find(u => u.id === item.id)` inside array `.map()` results in $O(N \times U)$ execution complexity (~4.7s for 1000 calls with 10k items). Pre-building a `Map` of updates (`updateMap.set(u.id, u.position)`) reduces lookup complexity to $O(N + U)$ (~393ms for 1000 calls, a ~12x speedup).
**Action:** When performing bulk updates on lists in state management stores based on an incoming array of partial updates, always convert the update array into a `Map` beforehand to avoid $O(N \times U)$ quadratic loops in mousemove/drag handlers.
