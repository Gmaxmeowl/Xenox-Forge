## 2025-05-18 - Memoizing Node Lookup Map in React Canvas / Graph View
**Learning:** In canvas/graph editors where elements (like scene nodes and connecting SVG transition paths) re-render frequently on user interactions (dragging, hovering, selecting), nested `.find()` operations in `Array.flatMap()` execute in $O(E \cdot N)$ time. Creating a memoized `Map` (`sceneMap`) converts node lookups into $O(1)$ operations, reducing re-render edge calculation time by ~10.5x (from ~1150ms to ~109ms for 1,000 scenes across 100 iterations). Additionally, when using `sceneMap` inside `useCallback` event handlers like `handleMouseUp`, include `sceneMap` in the dependency array to avoid stale closure references when scenes update.
**Action:** Always replace $O(N)$ nested `.find()` array operations inside render paths or drag handlers with a memoized `Map`, and ensure all `useCallback` functions using the Map include it in their dependency arrays.
