## 2026-11-08 - Nested Array Filtering and Array Find Anti-Pattern in List and Group Renderers
**Learning:** In collection views like `VariablesEditor.tsx` where items can be organized by category/group, rendering groups by iterating over them and running `filteredVars.filter(item => item.groupId === group.id)` incurs $O(G \times V)$ quadratic overhead on every re-render. Additionally, finding category metadata for each item in grid layouts via `groups.find(...)` adds another $O(V \times G)$ scan. Pre-bucketing items into a `Map<string, Item[]>` and caching metadata in a `Map<string, Group>` reduces rendering complexity to $O(V + G)$.
**Action:** When categorizing or tagging items in editor views, always use a single-pass `useMemo` partition to build group-to-items buckets and an ID-to-metadata Map instead of repeated nested `.filter()` or `.find()` calls in JSX render loops.
